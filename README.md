# If You Were Cockroach

3D cockroach survival mini-game built with Unity 2022.3.62f3c1.

## 试玩版

- [浏览器试玩版](https://liizyii.github.io/IfYouWereCockroach/)
- [Windows 试玩版下载](https://github.com/liizyii/IfYouWereCockroach/raw/main/Releases/IfYouWereCockroach-%E8%AF%95%E7%8E%A9%E7%89%88-Windows.zip)

Players do not need to install Unity, Blender, Git, or Visual Studio Code. For the Windows version, extract the zip and run `IfYouWereCockroach.exe`.

## Controls

- `WASD`: move
- Mouse: turn
- `Shift`: sprint
- `Space`: jump
- `E`: lay eggs while hidden
- `R`: restart
- `Q`: quit Windows build
- `Esc`: release mouse cursor
